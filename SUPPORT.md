# QuestBridge Support

Mac editions

Contact: mingistech@mac.com

## Connect Your Headset

Enable Developer Mode using Meta's setup process, connect a USB data cable,
keep the headset awake and unlocked, and approve USB debugging inside it.
A charging-only cable cannot transfer files. The App Store edition uses its own
authorization key, so you may need to approve it even if another app connects.

If the headset does not appear, try another data cable or USB port and inspect
Settings → Connection. Close other ADB applications before retrying; another
ADB server may own the connection. Avoid interrupting other transfers.

## Transfer Problems

Start with a small disposable file. Your Mac needs temporary space for a full
staging copy; downloading to the same disk may need twice the file size.
Replacements need enough destination space for a full new copy. Interrupted
transfers restart from the beginning.

Choose a remembered download folder again if it moved or its disk disconnected.
Ordinary file transfers do not need Photos permission. Read visible errors
before retrying. Do not remove unknown staging or backup files when recovering
valuable headset content.

## Licenses

Open Settings → Connection → Open ADB Licenses to read the bundled distribution
notice, third-party notices and LGPL text. Source and relinking materials must
match the ADB version supplied with your app; ask support if you cannot locate
the matching materials.

## Contact Support

Email mingistech@mac.com with the app version, macOS version, Mac architecture,
headset model/software version, cable type and reproduction steps. Review any
diagnostic text before sending it and redact private paths and identifiers.
Never send your ADB private key or sensitive media. A public issue tracker is
visible to other people; email is the private support channel.
